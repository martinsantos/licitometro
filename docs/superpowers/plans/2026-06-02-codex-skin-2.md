# Codex Skin 2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Raise the current LICITOMETRO Codex skin into a more legible, balanced, mature operational UI across core and secondary routes.

**Architecture:** Work in layers: first audit the current rendered UI and CSS, then recalibrate shared type/spacing/control primitives, then refine critical routes, then secondary routes, and finally verify with build, tests, diff checks, and Playwright screenshots. Keep changes in the existing React/CSS architecture and avoid a broad rewrite.

**Tech Stack:** React, TypeScript/JavaScript, Create React App, CSS/Tailwind utility classes already present in components, Jest/React Testing Library, Playwright visual QA.
